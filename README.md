Стъпки за клониране и стартиране на Next.js проект от GitHub
1. Копиране на линка от GitHub
   
   Отворете GitHub хранилището (Repository), натиснете зеления бутон Code и копирайте HTTPS линка.
2. Клониране на проекта
   
   Отворете терминала във VS Code и навигирайте до папката, в която искате да запазите проекта.
   
   Изпълнете командата:
   git clone https://github.com/kostoff05/Next.js.git
3. Влизане в папката на проекта
   
   След клонирането влезте в папката на хранилището:
   cd Next.js
   
   
   Тъй като хранилището съдържа няколко приложения, трябва да влезете и в папката на конкретния проект. Например:
   cd coffee-manager
4. Инсталиране на необходимите зависимости
   
   Изпълнете:
   npm install
   
   
   Тази команда прочита package.json и инсталира необходимите библиотеки и зависимости в папката node_modules.
5. Настройване на променливите на средата
   
   Ако проектът използва Supabase или Gemini API, създайте файл .env.local и добавете необходимите ключове:
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=...
   GEMINI_API_KEY=...
